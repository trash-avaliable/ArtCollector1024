## 提示词正文（从这里开始复制）

### 0. 一句话定义

做一个 Windows 桌面 exe：**画师的参考图收集器**。在浏览器里看到喜欢的图，右键或按一个键就能丢进去；程序自动归类（手部/脚部/线条/风格/教程……），能随时模糊搜索、浏览，画画时能直接拖进 PS/SAI 用。

### 1. 角色与工作方式

你是一名资深桌面应用工程师 + 交互设计师。请**先给出可运行的骨架**（能启动、能存图、能看列表），再按 P0→P1→P2 迭代，不要一次性写完所有模块导致跑不起来。

规则：
- 每个模块写完立即自测（启动、存一张图、搜一次、拖一次），报错先修再继续。
- 遇到需求未覆盖的细节，选**最简单且不破坏架构**的实现，并在代码里留 `// TODO:` 说明。
- 不引入无法离线运行的服务。除"可选的 AI 精修"外，断网必须全功能可用。

### 2. 技术栈（硬性要求）

| 层 | 选型 | 说明 |
|---|---|---|
| 外壳 | **Tauri 2**（Rust） | 目标是 exe 小、常驻内存低——画画时不能和 PS 抢内存 |
| 前端 | React 18 + TypeScript(strict) + Vite | |
| 样式 | Tailwind CSS + CSS 变量 | 不引入 AntD/MUI 等重型组件库，组件全部自绘以保证动效可控 |
| 动效 | Framer Motion | 只允许动 `transform` / `opacity` / `filter` |
| 数据库 | SQLite（rusqlite）+ FTS5(trigram) | 单文件，随库走 |
| 图像 | `image` crate + `fast_image_resize` | 后台线程生成缩略图 |
| 本地 AI | ONNX Runtime + CLIP ViT-B/32（量化） | 做图像向量与相似度，可选下载模型 |
| 浏览器扩展 | Chrome/Edge MV3 | 与桌面端通过 `127.0.0.1` 通信 |

> 若你的工具链装不了 Rust，可整体替换为 **Electron 35 + electron-builder**，其余需求一字不改；但需额外说明内存与体积代价。

### 3. 桌面应用形态（硬性要求）

**这一节决定它是"应用"而不是"网页"。8 条必须全部实现，缺一条不算完成。**

1. **无边框窗口**：`decorations: false`，标题栏自绘（48px，`--panel` 渐变 + 1px 底线）。整条标题栏是拖动区（`-webkit-app-region: drag`），其中所有按钮 / 输入框 / tab 标 `no-drag`。
2. **窗口可拖拽（移动 + 缩放）**
   - 移动：标题栏任意空白处 + 左轨顶部空白区都能拖。双击标题栏最大化 / 还原；拖到屏幕顶部（y < 8px）吸附最大化、拖离还原；拖到左右边缘做半屏吸附（Windows 原生行为要自己实现，Tauri 不自带）。
   - 缩放：四边 + 四角共 8 个 4px 热区，最小 960×640，最大不限。缩放过程用 `requestAnimationFrame` 节流，瀑布流重排延迟到 `resize` 结束 120ms 后执行，避免拖动时列表疯狂跳动。
3. **窗口状态记忆**：位置、尺寸、是否最大化、上次所在显示器写入 `settings`。125% / 150% / 200% DPI 与多显示器下坐标换算必须正确、不糊、不跑到屏幕外（恢复时校验矩形是否与任一显示器相交，否则居中）。
4. **关闭进托盘**：关闭按钮默认**收进托盘**而非退出；托盘右键菜单：打开 / 置顶参考窗 / 暂停剪贴板监听 / 立即整理待分类 / 退出。有待分类时托盘图标右下角一个 4px 黄块提示。
5. **单实例**：再次启动时唤醒已有窗口并聚焦（`single-instance` 插件）；若命令行带图片路径，直接入库。
6. **全局热键**：`Alt+Space` 唤起搜索面板（居中、失焦自动隐藏）、`Ctrl+Shift+S` 存下当前剪贴板图。
7. **置顶参考窗**：无边框独立窗口，`always_on_top`，透明度 10%–100% 可调，可切鼠标穿透（穿透时保留一条 6px 拖动条，该条本身不可穿透），支持多图并排与 `←/→` 翻页。
8. **首次引导**：无库时走引导（选库目录 → 是否装扩展 → 是否下载 CLIP 模型），绝不弹一个空白窗口让人发呆。

**拖拽系统（四层，都要能用鼠标一次完成）**

| 层 | 拖什么 | 拖到哪 | 反馈 |
|---|---|---|---|
| 窗口 | 标题栏 / 左轨空白 | 屏幕任意位置、边缘吸附 | 吸附前 80ms 显示半透明落位框 |
| 面板 | 右栏左边缘 4px 分隔条 | 左右拖动调宽 320–560px | 拖动中显示 1px 黑线 + 像素读数；双击复位 400px |
| 内容·内部 | 卡片（单选 / 多选 / 框选） | 左轨分类树节点、标签 chip、收藏区 | 目标节点 2px 黑框 + 右上角黄色楔形；非法目标光标 `not-allowed` |
| 内容·外部 | 卡片 / 大图 | PS、SAI、浏览器、微信、资源管理器 | native drag，导出临时原图 |

**拖拽硬性规则**

1. **拖拽副本必须和界面同语言**：卡片拖起后塌成白底 + 1px 黑框的线稿（只留边框、索引号、分类名），**不倾斜、不加投影、不缩放**，指针偏移 12px 跟随。跟手用 `pointermove` + `transform` 直改样式，不许逐帧 `setState`，延迟 ≤ 16ms。
2. **源卡片降到 40% 不透明度但保留占位**，不做"空位塌陷"，松手后 240ms 归位。
3. **命中判定用几何计算**，不吃 HTML5 `dragover` 的默认延迟；进入目标 80ms 内必须高亮。
4. **拖到左轨分类 = 改分类**，松手立即写库，右下角 5 秒可撤销回执。
5. **多选拖拽**：>1 张时副本显示 `×N` 角标；>20 张自动转为"打包拖出"（一个临时目录），避免 PS 卡死。
6. **拖出到外部**必须走系统 native drag（Tauri `start_drag`），导出原图到临时目录并在 5 分钟后清理，不能拿缩略图糊弄。
7. **拖拽期间暂停 hover 动效与扫描线**，减少重绘；`pointerup` 后 240ms 内恢复。
8. **所有拖拽都要有键盘等价路径**（`1-9` 改分类、`Ctrl+C` 复制图、`Enter` 送到上次目标），拖拽不能是唯一入口。
9. **防误触**：`pointerdown` 后位移 > 6px 才判定为拖拽；`Esc` 取消并归位；触控板双指滑动不得触发拖拽。

### 4. 核心场景（必须全部走通）

**S1 网页采集**
1. 用户在网页图片上右键 → 菜单出现「存到参考图收集器 ▸」，二级菜单直接列出最近使用的 6 个分类，点击即入库，全程 **≤ 2 次点击**。
2. 鼠标悬停在图片上 400ms，右下角浮出一个小圆钮（半透明，不遮挡图片），点一下 = 存到「待分类」收件箱，并弹出 3 个推荐分类供一键改判。
3. 快捷键 `Alt+Shift+S` 保存当前页面**所有** ≥300px 的图片，进入收件箱批量确认面板。

**S2 复制即收集**
桌面端常驻监听剪贴板。检测到图片（含网页复制的 `<img>`、截图工具、微信/QQ 复制）后，右下角滑出一张 220×140 的卡片：缩略图 + 推荐分类 + 三个按钮（存下 / 改分类 / 忽略），**默认 6 秒后自动收起但不入库**。按 `Ctrl+Shift+S` 可一键存下当前卡片内容。

**S3 存量图导入**
- 拖文件夹/多选文件进窗口 → 导入预览（去重提示：已存在 N 张）。
- 「从文件夹导入并**移动**」与「复制导入」两个选项，移动模式需二次确认并显示将影响的文件数。
- 导入时保留原文件的创建时间作为 `added_at` 参考，不修改源文件任何元数据。

**S4 自动分类**
四级管线，逐级兜底，**永远不丢图**：
1. **规则层**：来源域名 + 页面标题 + alt + 文件名 → 关键词表命中（如 `hand`/`手`/`anatomy` → 人体结构/手部）。
2. **视觉层**：CLIP 图像向量 vs 每个分类的文本原型向量（"a photo of a hand study" 等），取 top-3 与置信度。
3. **精修层（可选，默认关）**：置信度 < 0.55 时，调用用户自填的 OpenAI 兼容接口或本地 Ollama，返回 `{category, subcategory, tags[], caption}`。
4. **记忆层**：用户每次手动改分类都被记录；同一来源域名、同一标签组合的偏好会被加权，越用越准。

UI 表现：置信度 ≥0.75 静默归类；0.55~0.75 归类但卡片右上角显示淡黄色 `?` 角标；<0.55 进「待分类」。**任何时候用户都能一键改判，且改判后撤销 5 秒。**

默认分类树（可增删，支持二级）：

```
人体结构    手部 / 足部 / 头部五官 / 躯干动态 / 骨点关节 / 肌肉
动态与透视  姿势 / 运动线 / 透视网格 / 构图
线条练习    排线 / 线稿 / 速写 / 笔触质感
色彩与光影  配色方案 / 色卡 / 明暗关系 / 环境光 / 材质反射
美术风格    日系 / 欧美 / 厚涂 / 赛璐璐 / 水墨 / 像素 / 3D 辅助
教程与拆解  步骤图 / 教程长图 / 视频截图 / 文字笔记
服饰与道具  褶皱 / 布料 / 铠甲 / 武器 / 饰品
场景与背景  建筑 / 自然 / 天空 / 室内 / 氛围
表情与情绪  面部表情 / 肢体语言
灵感碎片    情绪板 / 未归类
待分类      收件箱
```

**S5 浏览**
- 三栏：左 = 分类树 + 智能集合（最近添加 / 最近使用 / 未分类 / 收藏 / 重复图）；中 = 瀑布流；右 = 详情（原图信息、标签、来源链接、相似图、使用记录）。
- 顶部一行：搜索框 + 已生效的筛选 chip（分类/标签/来源/颜色/尺寸/时间）。
- 键盘：`j/k` 上下移动，`space` 预览，`enter` 打开大图，`f` 收藏，`1-9` 快速改分类，`/` 聚焦搜索。
- 大图：滚轮缩放、拖拽平移、`←/→` 切换、`Esc` 关闭、双击 1:1、按住 `alt` 拖动 = 取色（复制 HEX）。
- 多选：框选 + `Shift` 连选，批量改分类/加标签/删除（删除进回收站，30 天可恢复）。

**S6 模糊搜索**
一个输入框搞定全部，命中优先级：完全匹配 > 拼音全拼 > 拼音首字母 > 中文子串 > 标签 > 描述文本 > 语义相似。
- 例：输入 `shou` / `sb` / `手部` / `手` 都应命中「手部」分类下的图。
- 中文用 FTS5 trigram 分词 + 拼音列（`pinyin`、`initials`）冗余存储；错字用 trigram 相似度兜底。
- 输入时 200ms 防抖，结果用 layout 动画平滑重排，无结果时给「按语义搜索」的降级入口。

**S7 取用（这是产品的价值终点，必须最顺）**
- **拖出**：从卡片或大图直接拖到 Photoshop / SAI / 浏览器 / 微信窗口，落到目标即插入（native drag，导出临时文件）。
- **复制**：右键 → 复制原图 / 复制压缩版（≤2MB）/ 复制文件路径。
- **置顶参考窗**：无边框小窗，可调透明度（10%~100%）、可鼠标穿透、可贴边自动收起、支持多图并排与 `←/→` 翻页。画画时它就是你的第二块屏。
- **快速唤起**：全局 `Alt+Space` 呼出搜索面板（居中 640px，Spotlight 式），输入即搜，`Enter` 直接复制到剪贴板，`Ctrl+Enter` 拖出。
- **工作集**：把本次画稿要用的 10 张图组成一个临时集合，一键在置顶窗里循环。

### 5. 数据与存储

```
<库根目录>/
  db.sqlite
  originals/2026/10/<sha256前2位>/<sha256>.<ext>
  thumbs/512/<sha256>.webp
  thumbs/128/<sha256>.webp
  trash/
```

- 内容寻址（sha256）→ 天然去重；重复导入只增加一条 `source` 记录，不复制文件。
- 表：`items`、`files`、`categories`、`tags`、`item_tags`、`sources`、`collections`、`embeddings`、`usage_log`、`settings`、`items_fts`。
- `usage_log` 记录每次"被取用"（拖出/复制/预览），用于「最近使用」与推荐排序。
- 库根目录可在设置里改，支持「迁移库」（复制 + 校验 + 切换，失败回滚）。

### 6. UI 美术方向（Endfield · 组件清透 · 全直角 · complex）

**设计契约**：`family = endfield`，`depth = complex`，表面系统 = **素底 + 组件微渐变**。
根节点写 `data-ark-theme="endfield" data-ark-depth="complex"`。

**三条底线（这一版的核心，不要越界）**

1. **圆角一律 0**。面板、卡片、按钮、胶囊、输入框、滚动条——全部直角，无任何例外。需要"圆"的地方改用方块（状态点改成 6px 方块，开关改成直角滑块）。
2. **背景是素的**。窗口底只有一个平涂色 `#eef0ea`。不铺环境光、不做全屏渐变、不做径向光晕、不做噪点、不做暗角。
3. **清透只发生在组件自身**。每个面板 / 卡片 / 按钮自己是一块从 `#ffffff` 到 `#f9fbf4` 的极浅竖向渐变，靠这一层"薄"显清透，而不是靠背景发光。

**禁止项**：`backdrop-filter`、`filter: blur()`、玻璃拟态、半透明模糊面板、大面积环境光、任何 `border-radius > 0`、霓虹渐变、扫描线故障抖动、假遥测数字。

**表面令牌**

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--bg` | `#eef0ea` 纯色 | 窗口底，唯一背景色 |
| `--panel` | `linear-gradient(180deg,#ffffff 0%,#f9fbf4 100%)` | 标题栏、主内容面板 |
| `--panel-2` | `linear-gradient(180deg,#fdfdf9 0%,#f4f7ee 100%)` | 左轨、次级面板 |
| `--card` | `linear-gradient(180deg,#ffffff 0%,#fcfdf8 100%)` | 素材卡 |
| `--dock` | `linear-gradient(178deg,#262a20 0%,#1b1d16 54%,#14160f 100%)` | 右栏、底部状态条（深色仪表） |
| `--grad-signal` | `linear-gradient(100deg,#fffa00 0%,#e9ff4f 100%)` | 主按钮底、选中楔形、活动条 |
| `--line` / `--line-2` | `#dfe3d7` / `#c7cdbd` | 1px 分层线 |
| `--ink` / `--muted` | `#1a1c17` / `#6f746a` / `#989d92` | 主文字 / 次文字 / 三级文字 |
| `--state` | `#00ffa2` | 仅"本地库已连接" |
| `--sh-1 / 2 / 3` | `0 2px 6px / 0 10px 24px / 0 26px 60px`，`rgba(28,34,24,.06/.12/.18)` | 卡片 / 悬停 / 窗口 |

黄色只做渐变块：主操作底、选中楔形、左轨活动条。**不做浅底上的黄字**；深色仪表栏里也不放黄字，只放白字 + 黄块。

**字体**

| 角色 | 字体栈 | 规格 |
|---|---|---|
| 大数字 | `"Arial Narrow","Roboto Condensed","DIN Condensed"` | 92px，`line-height:.76`，`letter-spacing:-.04em`，`background-clip:text` 做 `#1a1c17 → #6b7160` 渐变 |

| 索引 | `"IBM Plex Mono",monospace` | 12px，`tabular-nums` |

**尺寸（整体放大，按此执行，不要再缩）**

| 位置 | 值 |
|---|---|
| 左轨 / 标题栏 / 状态条 / 右栏 | 84 / 48 / 44 / 400px |
| 素材列数 | 3（1280 宽时每张 ≈222px） |
| 卡片图片高 | 140–200px（按原图比例，最小 140） |
| 卡片信息条 / 卡片内边距 / 卡片间隙 | 46 / 10 / 20px |
| 筛选条高 / 字号 | 38px / 13px |
| 主按钮 / 次按钮 | 56 / 50px |
| 面板内边距 | 22–26px |
| 圆角 | 0 |

**动效令牌（写进 CSS 变量，不许散落魔法数字）**

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--direct` | `240ms` | 所有直接交互：悬停、按下、归位、拖拽结束 |
| `--reveal` | `720ms` | 区块 / 列表载入 |
| `--attention` | `1800ms` | 常驻呼吸（待分类方块 + 选中校准框） |
| `--ease` | `cubic-bezier(.22,.8,.2,1)` | 默认曲线 |
| 位移 | 4–16px | 仅整屏转场允许更大行程 |

**动效（complex：三组动效族协同）**

1. **载入族**：卡片 `clip-path: inset(0 0 100% 0)` 自下揭开 + `translateY(16px)` + 淡入，逐张延迟 60ms，总 720ms（`--reveal`）。
2. **仪表族**：舞台扫描线每 7s 自上而下扫过一次（1px 黄→透明渐变）；选中卡片内嵌的校准框以 1800ms 呼吸（`opacity .18 ↔ .55`）；顶部刻度尺常驻不动。
3. **交互族（240ms，`--direct` + `cubic-bezier(.22,.8,.2,1)`）**：卡片悬停上浮 4px + 投影 `--sh-1 → --sh-2` + 图片放大 1.05 + 底部渐变遮罩 + 深色方块「拖入画布」浮现；筛选切换用 `translateX` 擦除而非淡入淡出；深色面板内的次级按钮悬停时背景提亮一档。

**动效纪律**

1. 点击后 100ms 内必须有视觉响应。
2. 只动 `transform / opacity / clip-path`；不动 `width / height / top / left`。
3. 常驻循环只允许两个：待分类呼吸（1800ms）、扫描线（7s）；其余循环视为 bug。
4. `prefers-reduced-motion` 下全部动画停止，卡片直接显示，扫描线隐藏。

**组件细节（全部直角）**

- **卡片**：`--card` 微渐变 + 1px `--line` 描边 + `--sh-1`；悬停升到 `--sh-2`。
- **选中**：`border: 2px solid var(--ink)` 占位换色（不做外环，避免布局跳动），右上角一个黄色斜切楔形 `clip-path: polygon(100% 0, 100% 100%, 0 0)`，内部 1px 校准框 1800ms 呼吸。
- **左轨导航**：84×62 直角格，激活项左侧 3px 黄色渐变竖条 + `--panel` 底。
- **右侧仪表**：`--dock` 深色渐变 + 1px 黑左边线；主按钮为黄色渐变直角块，左侧压一条 4px 黑色竖条做"工业缺口"；次按钮为 1px 白描边直角块。
- **筛选条**：直角块；选中项 `--ink` 底 + 白字，未选中 1px `--line` 描边 + 灰字。
- **大数字**：渐变文字（`#1a1c17 → #6b7160`），不描边、不发光、不加阴影。
- **空状态**：1px 线框直角画框 + 每 1800ms 一条横线扫过，配等宽字 `0 ITEMS`。

**信息密度**：卡片只有图 + 索引号 + 分类名 + 状态方块；尺寸、来源、使用次数全在右侧仪表栏。

**响应式**：≤1100px 时右栏落到内容下方（`order:3`，全宽，上边框 1px 黑），素材列 3 → 2；≤760px 单列，左轨收成 56px 图标轨。

### 7. 性能与稳定性指标（验收用）

- 冷启动 ≤ 1.5s（Tauri），常驻内存 ≤ 250MB（10000 张图库）。
- 瀑布流滚动 60fps；搜索 10000 张图响应 ≤ 120ms。
- 缩略图后台队列生成，导入 1000 张不阻塞 UI，进度可暂停/取消。
- 单张 >8000px 的图不得导致内存爆掉（流式解码 + 限制中间缓冲）。
- 支持 webp / avif / gif（动图存原文件，列表显示首帧）/ png / jpg / jpeg / bmp。
- 下载网页图时携带来源页 `Referer` 与 UA，处理防盗链；失败时回退到"仅记录链接 + 手动补图"。
- 崩溃后重启能自愈：数据库 WAL 模式，缩略图缺失自动重建。

### 8. 隐私

全部数据本地，不联网、不埋点、不登录。仅当用户主动开启「AI 精修」时才访问其自填的 API 地址，且首次开启需明确告知会上传图片。

### 9. 明确不要做

云同步 / 账号体系 / 社交分享 / AI 生图 / 内置画板 / 素材商店 / 弹窗式新手引导 / 默认系统标题栏 / 霓虹渐变 / 故障抖动 / 随机六边形与电路纹 / 无意义的假遥测数字 / 任何圆角 / 毛玻璃与 `backdrop-filter` / 全屏环境光与背景径向光晕。

### 10. 交付物

1. 可编译源码（`src/` 前端、`src-tauri/` 后端、`extension/` 浏览器扩展）。
2. `build.ps1`：一条命令产出 `RefCollector.exe` + NSIS 安装包 + 扩展 zip。
3. `README.md`：安装、库目录说明、完整快捷键表、扩展安装步骤（含开发者模式加载）。
4. 一份 `MOTION.md`：把第 6 节的动效令牌与组件动效落成代码里的实际参数表，方便后续调。

### 11. 里程碑

- **P0（能自己用起来）**：无边框窗口 + 自绘标题栏（可拖拽移动 / 边缘缩放 / 状态记忆）+ 本地库 + 拖入/粘贴导入 + 手动分类 + 瀑布流 + 模糊搜索 + 拖出/复制 + 托盘常驻。
